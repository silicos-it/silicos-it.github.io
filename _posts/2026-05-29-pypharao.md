We have just completed porting our well-known Pharao software as a Python module. This makes that using this module, users can perform pharmacophore searches from within a standard Python module and integrate it with other software like <a href="https://pandas.pydata.org">pandas</a>, <a href="https://scikit-learn.org/stable/"> scikit-learn</a> and <a href="https://www.rdkit.org">RDKit</a>. The GitHub repo with all documentation is available at <a href="https://github.com/silicos-it/PyPharao">github.com/silicos-it/PyPharao</a>. The original Pharao publication can be downloaded <a href="/assets/papers/hdw-pharao-paper.pdf" download>from here</a>.
