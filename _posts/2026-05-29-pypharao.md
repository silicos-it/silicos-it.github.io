We have completed the port of our well-known Pharao software to Python module. With this module, users can perform pharmacophore searches directly within a standard Python module and seamlessly integrate Pharao with libraries like <a href="https://pandas.pydata.org">pandas</a>, <a href="https://scikit-learn.org/stable/"> scikit-learn</a>, and <a href="https://www.rdkit.org">RDKit</a>. 

The GitHub repository, including full documentation, is available at <a href="https://github.com/silicos-it/PyPharao">github.com/silicos-it/PyPharao</a>. The original Pharao publication can be downloaded <a href="/assets/papers/hdw-pharao-paper.pdf" download>here</a>.
